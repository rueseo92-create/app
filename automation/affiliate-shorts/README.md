# 쿠팡 파트너스 자동화 (스레드 · 쇼츠)

**스레드는 완전 자동으로 게시하고, 쇼츠 영상은 매일 자동으로 만들어 두면 사람은 주 1회 10분만 씁니다.** 꾸준함이 필요한 부분은 전부 기계가 맡습니다.

```
[매일, 자동]  키워드 → 쿠팡 상품 검색 → Claude가 3개 골라 대본 → AI 음성 → 세로 영상 + 캡션
             → 프로필 링크 페이지 갱신                                  (맥 LaunchAgent)
[주 1회, 나]  npm run shorts -- week   → out/week.md
             week.md 맨 위 지시문을 Chrome의 Claude(또는 Aside)에 붙여 넣기
             → 각 플랫폼의 "예약 게시" 기능으로 하루 한 편씩 예약, 마지막 확인만 클릭
             npm run shorts -- done 1 2 3 ...
```

잊어버려도 괜찮습니다. 영상은 계속 쌓이고, 생각났을 때 `week`로 한 번에 예약하면 됩니다.

## 처음 한 번 설정 (맥)

```bash
cd automation/affiliate-shorts
brew install ffmpeg
npm install
cp .env.example .env        # 쿠팡 파트너스 API 키, Claude API 키 입력
npm run shorts -- auto --mock --dry-run   # 키 없이 연습: out/1/video.mp4 확인
./install-daily.sh          # 매일 10:00 자동 제작 시작 (해제: ./install-daily.sh remove)
```

- **키워드**는 `keywords.txt`에 한 줄씩 적습니다. 가장 덜 쓴 키워드부터 돌아가고, 한 번 소개한 상품은 다시 고르지 않습니다.
- **음성**은 맥 내장 한국어 음성(Yuna)을 씁니다. 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기에서 Yuna를 내려받으세요. 더 자연스러운 음성을 원하면 `GOOGLE_TTS_API_KEY`를 넣으면 됩니다.
- **프로필 링크 페이지**는 `site/index.html`입니다. Netlify Drop(app.netlify.com/drop)에 `site` 폴더를 끌어다 놓으면 주소가 생깁니다. 그 주소를 유튜브·인스타·틱톡 프로필 링크에 넣으세요.
- 쿠팡 파트너스 API 키는 **최종 승인된 계정**만 받을 수 있습니다. 승인 전에는 `--mock`으로 연습하세요.

## 스레드 완전 자동 게시

스레드는 Meta가 공식 게시 API를 열어 두어서 **사람 손 없이 매일 자동으로** 올릴 수 있습니다. 위장이나 우회가 필요 없습니다.

```
[하루 3번, 자동]  글 종류 고르기 → Claude가 PERSONA 말투로 작성 → 점검 → 게시
  · 살림 팁 글(링크 없음)      15
  · 참여 질문 글(링크 없음)     5     ← 30개 기준 비율, 수익화 글은 연달아 두지 않음
  · 수익화 글(첫 댓글 링크)    10
```

**수익화 글은 "물건이 아니라 상황"을 씁니다.** 4칸 구조(상황 훅 → 디테일 → 반전 → 질문), 7줄 이내로 씁니다. 본문에는 제품명을 넣지 않고, "정확히 뭔지는 첫 댓글에"로 끝냅니다. 첫 줄 유형(자책형, 일상 짜증형, 질문형, 상식 반박형, 부정 명령형)은 돌아가며 씁니다.

**초기 계정 보호:** 첫 7일은 링크 글 없이 팁·질문 글만 올리고(`THREADS_LINK_AFTER_DAYS`), 14일까지는 하루 2개까지만 올립니다.

**성과 반영:** 게시 1~7일 뒤 조회수·좋아요·댓글을 자동으로 모읍니다. 반응 좋았던 첫 줄은 다음 글을 쓸 때 "구조만" 참고시킵니다. `npm run shorts -- threads-stats`로 글 종류별, 첫 줄 유형별 평균 조회수를 볼 수 있습니다.

**하지 않는 것:** 겪지 않은 일상을 지어내기, 써 본 척·사 본 척("샀다가 후회"), 터진 글을 문장만 바꿔 다시 올리기, 봇처럼 안 보이게 꾸미기. 계정 정지와 기만 광고 위험이 수익보다 큽니다.

처음 한 번만 연결하면 됩니다(20분).

1. developers.facebook.com → 앱 만들기 → 사용 사례 **"Threads API 액세스"** 선택
2. 사용 사례 설정에서 권한 `threads_basic`, `threads_content_publish`, `threads_manage_replies`, `threads_manage_insights` 추가
3. 설정에서 **리디렉션 콜백 URL**에 `https://localhost/` 등록
4. 앱 역할 → **Threads 테스터**에 내 스레드 계정 추가 → 스레드 웹(threads.com) 설정 → 계정 → 웹사이트 권한 → 초대 수락
5. App ID / App Secret을 `.env`에 넣고:
   ```bash
   npm run shorts -- threads --mock --dry-run   # 글 미리보기 (게시 안 함)
   npm run shorts -- threads-login              # 브라우저에서 허용 → 주소창 주소 붙여 넣기
   npm run shorts -- threads                    # 첫 글 직접 올려 보기
   ./install-threads.sh                         # 매일 09:40 13:10 20:20 자동 게시
   ```

- 내 계정에 올리는 것은 테스터 권한으로 됩니다. 메타 앱 검수는 다른 사람 계정에 올리는 서비스를 만들 때만 필요합니다.
- 토큰은 60일짜리이고, 실행될 때마다 알아서 갱신합니다. **맥이 60일 넘게 한 번도 실행하지 않으면** `threads-login`을 다시 해야 합니다.
- 글 점검에 두 번 걸리면 그 회차는 올리지 않고 `out/threads.log`에 사유를 남깁니다. 같은 상품은 두 번 올리지 않습니다.
- 말투는 `.env`의 `PERSONA` 한 줄로 바꿉니다. 콘셉트는 자유지만, 자동으로 쓰는 글이라 "써 봤다"는 표현은 막혀 있습니다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `auto` | 하루 한 편 자동 제작 (LaunchAgent가 매일 실행) |
| `week` | 쌓인 영상의 주간 예약 체크리스트 `out/week.md` |
| `done 3 4 5` | 예약 끝난 영상 표시 |
| `threads-login` | Threads 계정 연결 (처음 한 번) |
| `threads` | 스레드 글 하나 자동 작성·게시 (`--dry-run`이면 미리보기만) |
| `threads-stats` | 스레드 성과 요약 |
| `list` | 전체 목록과 상태 |
| `search 키워드` / `make 키워드 --pick N` / `render N --media 폴더` | 직접 촬영해 만드는 수동 모드 |

## 왜 자동 "게시"는 하지 않나

- 유튜브·인스타·틱톡은 공식 API 심사를 받지 않은 자동 업로드를 막거나 비공개로 잠급니다. 사람처럼 보이게 꾸민 자동 업로드는 약관 위반이라, 걸리면 계정 정지와 파트너스 수익 몰수가 같이 옵니다.
- 그래서 **각 플랫폼이 공식 제공하는 예약 기능**을 씁니다. 내 브라우저에서 내가 보는 앞에서 Claude가 입력을 대신하고, 마지막 확인은 내가 누릅니다. 일주일치를 한 번에 예약하니 꾸준함이 필요 없습니다.

## 지키는 것

- 대가성 문구는 코드가 캡션 첫 줄에 넣고, 영상 상단에도 처음부터 끝까지 표시합니다. 예약 지시문에도 "문구를 지우지 말 것"이 들어 있습니다.
- 대본은 직접 써 본 척하지 않고, 상품명·가격·배송 정보에 없는 효능이나 순위를 지어내지 않습니다. "최저가·무조건·1위" 같은 표현이 나오면 한 번 고쳐 쓰게 하고, 그래도 걸리면 그날 영상은 만들지 않습니다.

## 알아 둘 위험

- 상품 사진에 AI 음성을 입힌 영상은 플랫폼이 "반복·저품질 콘텐츠"로 보고 노출을 줄일 수 있습니다. 한 카테고리로 묶고, 반응 좋은 영상은 가끔 직접 찍은 버전(수동 모드)으로 다시 만들어 보세요.
- 쿠팡 상품 이미지를 영상에 쓰는 것이 허용되는지 파트너스 약관에서 확인하세요.
- 쿠팡 API 응답 형식은 공식 샘플 기준으로 짰고, 실제 키로는 아직 시험하지 않았습니다. 첫 실행 기록(`out/daily.log`)을 한 번 확인하세요.

## 수익 현실

수수료는 대부분 구매액의 약 3%이고, 링크를 누른 뒤 24시간 안의 구매만 인정됩니다. 1만 원짜리가 100개 팔려야 약 3만 원입니다. 결국 조회수 × 프로필 방문율 × 구매율의 게임이라, 첫 한두 달은 어떤 키워드가 먹히는지 찾는 기간으로 보세요. `COUPANG_SUB_ID`를 플랫폼별로 나누면 어디서 팔렸는지 볼 수 있습니다.
