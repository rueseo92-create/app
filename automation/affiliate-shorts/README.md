# 쿠팡 파트너스 쇼츠 파이프라인

쿠팡 상품 하나를 고르면 **촬영표 → 자막 입힌 세로 영상 → 채널별 캡션 → 프로필 링크 페이지**까지 만들어 주는 도구입니다. 유튜브 쇼츠, 인스타 릴스, 틱톡에 같이 씁니다.

```
search 키워드        쿠팡 상품 검색 (파트너스 오픈 API)
make 키워드 --pick N  Claude가 촬영표·자막·캡션 작성, 대가성 문구 자동 삽입, 위험 표현 점검
(직접 촬영)          shotlist.txt 대로 휴대폰으로 4~6컷
render 번호 --media 폴더  1080x1920 영상 + 자막 + "광고" 표시 고정
landing              "영상 속 N번" 프로필 링크 페이지
(업로드)             앱에서 음악 넣고 captions.txt 붙여넣기
```

## 왜 이런 구조인가

- **쇼츠·릴스·틱톡 캡션 링크는 눌리지 않습니다.** 그래서 영상 끝에 "프로필 링크 N번"을 띄우고, 프로필에 걸린 페이지 하나에 상품을 모읍니다.
- **영상은 직접 찍은 소재로 만듭니다.** 상품 이미지만 이어 붙인 영상은 유튜브의 "재사용·반복 콘텐츠" 정책에 걸려 수익화가 막히기 쉽습니다. 플랫폼 노출도 실제 사용 장면이 훨씬 잘 됩니다.
- **대가성 문구는 코드가 붙입니다.** AI에 맡기지 않습니다. 캡션 첫 줄과 영상 상단에 처음부터 끝까지 들어갑니다. 문구가 빠지면 파트너스 수익이 몰수될 수 있습니다.
- **업로드는 사람이 합니다.** 초기 계정이 자동 업로드를 하면 스팸으로 분류되기 쉽고, 앱 안에서 트렌드 음악을 넣어야 노출이 잘 됩니다. 익숙해진 뒤 Buffer나 Hycli로 예약 게시를 붙이세요.

## 설치

```bash
cd automation/affiliate-shorts
npm install
cp .env.example .env   # 키 입력
brew install ffmpeg    # macOS
```

- 쿠팡 파트너스 오픈 API 키는 **최종 승인된 계정**만 발급받을 수 있습니다. 승인 전에는 `--mock`으로 흐름을 연습하고, 링크는 파트너스 웹에서 직접 만드세요.
- Claude 키가 없으면 `--dry-run`으로 기본 템플릿 기획을 씁니다.

## 사용 예

```bash
npm run shorts -- search 실리콘 밀폐용기
npm run shorts -- make 실리콘 밀폐용기 --pick 2
#   out/1/shotlist.txt 보고 촬영 → ~/Movies/1 에 1.mp4, 2.mp4 ... 저장
npm run shorts -- render 1 --media ~/Movies/1
npm run shorts -- landing      # site/ 폴더를 GitHub Pages·Netlify 등에 배포
npm run shorts -- list
```

연습: `npm run shorts -- make 아무거나 --mock --dry-run`

## Claude Code·Orca에서 쓰기

이 폴더에서 Claude Code에 이렇게 맡기면 됩니다.
> "주방용품 키워드 5개로 상품 찾아서 리뷰 많고 로켓배송인 것 3개 골라 make 해 줘. shotlist 요약해 줘."

Hycli를 연결해 두면 업로드나 파트너스 실적 조회 같은 로그인 작업도 이어서 맡길 수 있습니다. 게시처럼 쓰기 동작은 꼭 승인을 켜 두세요.

## 수익 현실

- 수수료는 대부분 구매액의 약 3%입니다. 클릭 후 24시간 안의 구매만 인정됩니다. 1만 원짜리 상품 100개가 팔려야 3만 원입니다.
- 결국 **조회수 × 프로필 방문율 × 구매율**의 게임입니다. 카테고리(살림, 주방, 자취템처럼) 하나를 정하고 매일 1~2개씩 꾸준히 올리는 계정이 이깁니다.
- 첫 달은 어떤 훅과 상품이 먹히는지 찾는 기간입니다. 파트너스 채널 ID(`COUPANG_SUB_ID`)를 플랫폼별로 나눠 두면 어디서 팔렸는지 볼 수 있습니다.

## 지키는 것

- 대가성 문구는 캡션 첫 줄에 있고, 영상 화면에도 처음부터 끝까지 표시합니다.
- 써 보지 않은 효과나 근거 없는 "최저가·1위"는 쓰지 않습니다. `make`가 해당 표현을 표시해 줍니다.
- 여러 계정으로 같은 영상을 뿌리거나 댓글·조회수를 조작하지 않습니다. 계정 정지와 수익 몰수 사유입니다.
- 쿠팡 API 응답 형식은 첫 실제 호출에서 한 번 확인하세요. 이 코드는 공식 샘플 기준이고, 실제 키로는 아직 시험하지 않았습니다.
